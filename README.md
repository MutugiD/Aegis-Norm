# Aegis-Norm

An inference product specification for a native CUDA RMSNorm library, Hugging Face integration, and a small streaming demo on contributor-operated T4 GPUs.

**Current status: research and documentation.** Kernel, model, and serving results are not yet measured. There is no installable inference implementation yet.

Start with the [master plan](doc/00-master-plan.md) and [documentation index](doc/README.md). The [original context](context.txt) is preserved; its claims are audited rather than treated as established results.
