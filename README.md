# Aegis-Norm

Aegis-Norm is an inference product initiative centered on native CUDA RMSNorm, Hugging Face integration, and a small streaming demo on contributor-operated T4 GPUs.

**Current status: research and documentation.** The repository contains a master plan, primary-source research, compatibility candidates, and CI for documentation and Python validation tooling. Kernel, model, and serving results are not yet measured. The inference application is not implemented yet.

The [master plan](doc/00-master-plan.md) defines scope and delivery. The [documentation index](doc/README.md) maps the current material. The [original collected ideas](context.txt) are exploratory input, not authoritative requirements or validated code. A subsequent documentation increment curates them into a structured product-context document.
